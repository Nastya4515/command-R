## Известные потери и их причины

- **P009 — вся статья без результатов.** Грязный текстовый слой: цитаты
  модели не сходятся с текстом PDF, сверка отклонила все 156 кандидатов.
  Осознанное решение: лучше пропустить статью, чем сдать непроверяемые данные.
- **P017 (стр. 19), P058 (стр. 11, 3 строки таблицы)** — страницы, где модель
  не вернула валидный JSON даже после корректирующего запроса.
- **4698 ненайденных цитат** — в основном сканированные страницы без
  текстового слоя (чекер сам пишет «no text layer/OCR text on this page»)
  и страница P085 с битой кодировкой (ушла на vision-OCR).
- **Значения с графиков не оцифровываются** (допущение конвейера): на dev
  это до ~30% эталонных значений статьи (в D001 — 51 из 383).
